# AGENTS.md

Инструкции для ИИ-агентов. Файл кросс-инструментальный (AGENTS.md читают многие агенты).
Подробный источник правды — [CLAUDE.md](CLAUDE.md); этот файл его дополняет и на него ссылается.

## Что это

Персональный сайт-портфолио продуктового дизайнера, свёрстанный по макету Figma.
Готова главная страница; страница кейса свёрстана до раздела «Введение».

Проект русскоязычный: код, комментарии, коммиты и документация — по-русски.

## Стек и сборка

Astro 7 (статическая генерация, без клиентского JS на главной), TypeScript, npm.
Шрифт Manrope через встроенный Fonts API. Контент кейсов — content collections.

Astro 7 новее, чем знания большинства моделей: **проверяй незнакомые API по
установленным `.d.ts`, а не по памяти.** Список конкретных грабель (scoped-стили,
zod v4, склейка текстовых узлов) — в [CLAUDE.md](CLAUDE.md#особенности-astro-на-которых-легко-ошибиться).

## Как запускать и проверять

```bash
npm install
npm run dev       # разработка на http://localhost:4321
npm run build     # сборка в dist/
npm run preview   # посмотреть собранный сайт
npm run check     # astro check: типы и шаблоны
```

Тестов в проекте нет — не ссылайся на `npm test`.

**Что проверяется само:** `npm run check` (должно быть 0 ошибок / 0 предупреждений /
0 подсказок) и `npm run build`. Неизвестное имя иконки валит сборку осознанно.

**Чем проверяется вёрстка:** скриншот собранной страницы через Playwright +
предустановленный в окружении Chromium, дифф по зонам против рендера макета 1:1 и
сверка геометрии с числами макета. Полный рецепт и опорные числа —
[CLAUDE.md](CLAUDE.md#как-проверять-вёрстку). Playwright **намеренно не в
зависимостях** — не добавляй его в `package.json`.

**Чего проверить нельзя:** реальные шрифтовые метрики других браузеров (Chromium и
Figma расходятся на жирном тексте), поведение в Safari, живой Vercel до пуша в `main`.
Не выдавай это за проверенное.

## Ключевые ограничения

- **Внешний вид сверяется с Figma, а не с памятью или скриншотом панели свойств.**
  Всегда `get_design_context` на узле: панель показывает и отключённые слои, а часть
  значений (радиус размытия) в неё не попадает.
- **У повёрнутых слоёв метаданные Figma врут** — отдают точку привязки, а не угол
  габаритной рамки. Считай через матрицу поворота и сверяй попиксельно.
  См. [ловушку в CLAUDE.md](CLAUDE.md#ловушка-у-повёрнутых-слоёв-метаданные-врут).
- **Только десктоп (1360px) и только русский** — осознанные границы этапа, не «баг».
- Есть [известные расхождения с макетом](CLAUDE.md#известные-расхождения-с-макетом),
  которые не надо «исправлять» заново.

## Конвенции

- **Никаких литеральных цветов и размеров шрифта в компонентах** — только переменные
  из `src/styles/tokens.css`. Новое значение получает пометку источника: `[var]`
  (из переменных Figma) или `[pipette]` (снято с рендера).
- **`text-wrap: balance` во всём тексте** — объявлено на `body` в `global.css`
  и наследуется. В компонентах `text-wrap` не дублируется и не отключается.
- Данные владельца — `src/data/profile.ts`, подписи интерфейса — `src/data/ui.ts`.
  В разметке текст не хардкодится.
- Иконка добавляется файлом в `src/icons/`, правки в `Icon.astro` не нужны.
- Кейс добавляется файлом в `src/content/cases/`, поля проверяются схемой.
  Текст страницы кейса — в поле `sections` того же файла, а не в теле markdown:
  разметка страницы жёсткая, блоки типизированы. Тело файла не используется.
- Комментарии объясняют **почему**, а не что: откуда взялось число, какую ловушку
  обходит приём.

## Работа с git

Разработка ведётся в рабочей ветке, продакшн обновляется **только пушем в `main`**.
Пул-реквесты не создаются без явной просьбы.
